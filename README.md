# pyf-automl

本工程为基于 autogluon 扩展的自动化机器学习镜像工程，可快速创建自动化机器学习镜像环境，并提供了一个使用的简单的示例

## 构建镜像

将本工程拉取到环境部署节点中，于工程路径下执行以下脚本进行镜像构：

```
./build.sh
```

镜像体积较大，需要网络环境正常并等待一定的时间

默认构建的镜像名称为：

```
pyf-automl:1.6.3
```

## 运行镜像

镜像构建好之后在工程路径下执行以下脚本可运行镜像容器：

```
./run.sh
```

运行之后会自动启动 jupyter 环境，映射端口为默认端口 8888，访问 http://{ip}:8888 可操作 jupyter，其中 {ip} 为容器启动节点的 ip 地址

容器在运行的过程中在工程路径下执行以下脚本可在部署节点终端实时显示容器运行日志：

```
./log.sh
```

如果需要终止容器运行，可在工程路径下执行以下脚本：

```
./stop.sh
```

## 运行测试

本工程在运行容器时会将工程目录下的 /code 目录映射到容器内的工作路径，该路径下包含了一个测试 notebook 脚本：

```
test-igis-automl.ipynb
```

于 JypyterLab 中访问并调试该脚本可测试容器运行
